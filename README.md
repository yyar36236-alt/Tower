# 🗼 Tower — плавающая панель управления видео

**Tower** — это Android-приложение в формате APK, которое добавляет поверх любых
приложений плавающее меню с **30 функциями для видео** (6 разделов). Внутри окна —
свой браузер/плеер, поэтому YouTube и любое другое видео открываются прямо в
плавающем окне и полностью управляются панелью.

> Скорость **2X · 3X · 4X · 5X · 10X** — и любой шаг от **0.25X** до **16X**.

---

## 📦 Установка

1. Откройте раздел **[Releases](../../releases)** → скачайте `Tower-v1.0.apk`
   (после первой сборки готовый файл лежит и в репозитории:
   [`release/Tower-v1.0.apk`](release/Tower-v1.0.apk)).
   Если APK ещё нет — один раз активируйте автосборку, см. 👇 **«Автосборка APK»**.
2. Разрешите установку из неизвестных источников для браузера/файлового менеджера.
3. Установите APK и откройте Tower.
4. Нажмите **«Выдать»** для пункта *«Показ поверх других приложений»* — это главный доступ,
   без него меню не сможет «летать» поверх YouTube, браузера и игр.
5. (Желательно) включите **Специальные возможности → Tower** — тогда панель рисуется
   системным слоем, не пропадает и сама воскресает после выгрузки.
6. Нажмите **«ЗАПУСТИТЬ ПАНЕЛЬ»**.

Дальше панель всегда сверху: сверните её в пузырь кнопкой **«—»**, верните — тапом по пузырю.

## 🎯 Где какая функция работает

| Раздел | Где работает |
|--------|--------------|
| СКОРОСТЬ, ВОСПРОИЗВЕДЕНИЕ | В окне Tower (YouTube, VK, Rutube, Twitch, любые сайты с `<video>`, прямые ссылки `.mp4`/`.m3u8`) |
| YOUTUBE | В окне Tower на youtube.com |
| ВИДЕО (снимок, запись) | **Везде**, поверх любого приложения |
| ЗВУК | **Везде**, системно — даже в обычном приложении YouTube |
| ЭКРАН | **Везде**, системно |

### Почему скорость работает именно так
Android не даёт стороннему приложению менять скорость воспроизведения **внутри чужого
приложения** (в приложении YouTube, в Chrome) — это может только само приложение.
Поэтому Tower открывает видео **у себя** в плавающем окне и там управляет им полностью:
ставит `playbackRate`, перематывает, режет рекламу. Это единственный легальный способ
получить 10X на Android без root.

## 🔐 Какие доступы нужны

| Доступ | Обязательно? | Зачем |
|--------|--------------|-------|
| **Показ поверх других окон** (`SYSTEM_ALERT_WINDOW`) | ✅ да | Чтобы меню «летало» поверх всех приложений |
| **Специальные возможности** (Accessibility) | ⭐ желательно | Системный слой окна + панель не выгружается и сама воскресает. Tower **не читает текст с экрана**, не перехватывает ввод и ничего не отправляет |
| **Уведомления** | ⭐ желательно | Постоянная работа сервиса и кнопка «Остановить» |
| **Захват экрана** (MediaProjection) | по требованию | Только для функций «Снимок экрана» и «Запись экрана», спрашивается системным диалогом в момент нажатия |
| **Отключение оптимизации батареи** | ⭐ желательно | Чтобы панель не пропадала через час |
| **Автозапуск после перезагрузки** | по желанию | Включается в настройках приложения |

Root не нужен. Интернет нужен только для загрузки самих видео.

## 🚀 Автосборка APK (GitHub Actions) — включить один раз

Workflow лежит в файле [`ci/apk.yml`](ci/apk.yml). GitHub Actions выполняет workflow
только из каталога `.github/workflows/`, а приложение Arena не имеет права создавать
файлы в этом каталоге — поэтому файл нужно **один раз** положить вручную:

1. Откройте [`ci/apk.yml`](ci/apk.yml) на GitHub и нажмите **Raw**, скопируйте содержимое
   (≈130 строк YAML).
2. Откройте ссылку — путь файла в ней уже подставлен:
   **[➜ создать `.github/workflows/apk.yml`](https://github.com/yyar36236-alt/Tower/new/main?filename=.github%2Fworkflows%2Fapk.yml)**
3. Вставьте скопированный текст и нажмите **Commit changes → Commit directly to the `main` branch**.

Всё: этот же push запустит сборку. Дальше каждый push в ветку будет автоматически:

* собирать `Tower-v1.0.apk` (release, подписанный) и `Tower-debug.apk`;
* складывать их в артефакт `Tower-APK`;
* обновлять релиз **v1.0**;
* класть `release/Tower-v1.0.apk` прямо в репозиторий.

Альтернатива — собрать локально:

```bash
gradle wrapper --gradle-version 8.7     # один раз, чтобы появился ./gradlew
./gradlew assembleDebug                 # debug APK
./gradlew assembleRelease               # release APK
```

## 🛠 Сборка из исходников

```bash
# Gradle 8.7 и JDK 17
gradle wrapper --gradle-version 8.7     # один раз, чтобы появился ./gradlew
./gradlew assembleDebug                 # debug APK
./gradlew assembleRelease               # release APK
```

Готовый APK собирается автоматически в GitHub Actions (`.github/workflows/apk.yml`):
каждый push → артефакт `Tower-APK` и релиз `v1.0`. Если в коммите есть `[apk]`,
собранный файл дополнительно кладётся в `release/Tower-v1.0.apk`.

Подпись: берётся keystore из секретов (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`),
если секретов нет — генерируется на лету.

## ⚠️ Известные ограничения

* Вход в аккаунт Google внутри встроенного браузера недоступен (Google блокирует
  авторизацию в WebView) — смотреть видео это не мешает.
* `m3u8`-потоки играются через hls.js, который подгружается из интернета; без сети
  такой поток может не открыться.
* Усиление звука и эквалайзер работают через системные эффекты `LoudnessEnhancer` /
  `Equalizer` на общем аудиовыходе — на редких прошивках они могут быть отключены
  производителем (тогда приложение честно напишет «не поддерживается»).
* Функции раздела YOUTUBE завязаны на CSS-классы плеера YouTube — если YouTube
  изменит вёрстку, селекторы обновятся в следующих версиях.

## 📁 Структура

```
app/src/main/java/com/tower/app/
├── overlay/
│   ├── FloatingService.kt   — плавающее окно, WindowManager, WebView, 30 функций
│   ├── PanelUi.kt           — панель: 6 разделов, кнопки, ползунки
│   └── NightOverlay.kt      — ночной фильтр (системный слой)
├── audio/AudioTools.kt      — системное усиление, эквалайзер, громкость
├── capture/CaptureTools.kt  — MediaProjection: снимок и запись экрана
├── service/
│   ├── TowerAccessibilityService.kt — системный слой и живучесть панели
│   └── BootReceiver.kt      — автозапуск
├── ui/                      — MainActivity, SettingsActivity, CaptureActivity
├── Functions.kt             — реестр из 30 функций
├── TowerJs.kt               — JS-движок: скорость, реклама, фокус, PiP
└── Prefs.kt                 — настройки
```

Лицензия: используйте как хотите. Приложение не собирает и не отправляет никаких данных.
